# Task spec template

Copy this into a new chat for an executor model. Keep it under one screen.

```
Read @AGENTS.md first.

Task: <one sentence>
Phase: <roadmap phase>

Files you may change:
- <path>
- <path>

Files to read for context (nothing else):
- <path>

Requirements:
1. <specific, testable>
2. <specific, testable>

Out of scope:
- <things the model might be tempted to do>

Done when:
- npm test and npm run typecheck pass
- <acceptance check>

Reply with: files changed, test results, open issues. No explanations.
```
